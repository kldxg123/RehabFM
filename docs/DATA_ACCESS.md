# Data access

`data_sources/datasets.csv` links the published source for every public dataset. Obtain datasets from their providers and comply with the source-specific license, credentialing and ethics conditions. The repository does not bundle data or grant redistribution rights.

Published participant counts describe source cohorts, not the number of distinct participants retained by each historical adapter. Unknown clinical status is marked NR. GaitRec has a published count discrepancy (2,084 in the abstract/Table 1 versus 2,085 elsewhere). Nordic participant identity and some HS-Stroke and ULTRA-MoCap archive mappings remain unresolved. These limitations are retained rather than replaced with inferred counts.

Institutional patient records, identifiers, group/split arrays, labels, features, individual predictions/probabilities, model weights, optimizer states and the ethics approval scan are excluded. The manuscript reports underlying study approval 2026bkky-039; confirmation of consent/waiver and the precise present-analysis approval scope remains necessary. Public code availability is not authorization to access or redistribute clinical data.
